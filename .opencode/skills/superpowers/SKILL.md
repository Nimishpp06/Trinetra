## What I do
- **TDD loop**: Red (write failing test) -> Green (make it pass) -> Refactor (clean up)
- Write tests before or alongside implementation, not after
- For every bug: reproduce -> isolate root cause -> write regression test -> fix -> verify
- Use Vitest/Jest for frontend, appropriate test runner for backend
- Maintain minimum 70% coverage on critical paths
- Structure plans with: Goal -> Approach -> Steps -> Verification

## When to use me
Use this when implementing new features, fixing bugs, or refactoring. Skip for one-off scripts or exploration.
